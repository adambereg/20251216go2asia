## 1. Область тестирования

### 1.1 Компоненты
- **API:** `GET /v1/guides` (Content Service)
- **Модель данных:** `guides`, `guide_sections`, `guide_blocks`, `guide_feeds`
- **Интеграции:** Atlas (countries/cities/places), Pulse, Blog, Rielt, Quest
- **Валидация:** блоки, секции, feeds

### 1.2 Типы гайдов
- `strategic`, `comparative`, `route`, `niche`, `event`, `housing`, `visa`, `work_infra`, `climate`

### 1.3 Типы блоков
- **Базовые:** `rich_text`, `callout`, `bullets`, `key_facts`, `media`, `divider`
- **Структурные:** `checklist`, `steps`, `timeline`, `day_plan`, `table`, `scorecard`
- **Географические:** `map_config`, `poi_refs`, `city_refs`
- **Социальные:** `faq`, `related_guides`
- **Интеграционные:** `feed_embed`

## 2. Чеклисты по гейтам

### Гейт B: Валидация секций и блоков

#### B.1. Кейсы непустых/пустых секций

**Приоритет:** 🔴 P0 (Critical)

| ID | Тест-кейс | Ожидаемый результат | Статус |
|----|-----------|---------------------|--------|
| B.1.1 | Секция с `is_enabled=true` и хотя бы одним непустым блоком | Секция отображается в ответе API | ⬜ |
| B.1.2 | Секция с `is_enabled=true` и активным `feed` (enabled=true) | Секция отображается даже без блоков | ⬜ |
| B.1.3 | Секция с `is_enabled=true`, но все блоки пустые и feed отсутствует/disabled | Секция **не отображается** | ⬜ |
| B.1.4 | Секция с `is_enabled=false` | Секция **не отображается** независимо от блоков | ⬜ |
| B.1.5 | Секция с `is_enabled=true`, блоки содержат только пробелы/переносы строк | Секция **не отображается** (блоки считаются пустыми) | ⬜ |
| B.1.6 | Секция с `is_enabled=true`, один блок непустой, остальные пустые | Секция отображается | ⬜ |
| B.1.7 | Секция с `is_enabled=true`, feed `enabled=true`, но блоки пустые | Секция отображается | ⬜ |
| B.1.8 | Секция с `is_enabled=true`, feed `enabled=false`, блоки пустые | Секция **не отображается** | ⬜ |

**Критерии "непустого" блока:**
- Для `rich_text`: `content` не пустой, длина > 0 после trim
- Для `bullets`: массив `items` не пустой
- Для `media`: массив `media_urls` или `media_ids` не пустой
- Для `divider`: всегда считается пустым (см. негативные кейсы)
- Для `feed_embed`: `feed_id` валиден и feed `enabled=true`
