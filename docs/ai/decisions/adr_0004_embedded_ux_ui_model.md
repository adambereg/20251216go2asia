# ADR-004: Embedded UX/UI Director Model (MVP Stage)

## Статус
Accepted

## Дата
2025-XX-XX

---

## Контекст

В текущем pipeline разработки Go2Asia отсутствует отдельная фаза UX/UI-дизайна.
UI-решения формировались непосредственно на этапе Frontend-реализации,
что приводило к:

- импровизации визуальной структуры;
- несоответствию прототипов и реализации;
- ухудшению консистентности интерфейсов;
- увеличению количества UI-итераций.

При этом:

- добавление нового Tier-1 агента нарушило бы минималистичную структуру MVP (см. ADR-003);
- изменение pipeline создало бы дополнительную сложность;
- текущий этап развития проекта требует плотной интеграции дизайна и реализации.

---

## Решение

Внедрить UX/UI Director как **embedded sub-mode внутри роли Frontend Dev**.

Особенности модели:

1. UX/UI Director не является отдельным агентом.
2. UX/UI реализуется как sub-mode Frontend Dev.
3. Перед реализацией UI обязательно фиксируется визуальная спецификация (`.pen` через Pencil).
4. Код реализуется строго по `.pen`.
5. UI-итерации управляются через iteration_rules.
6. Новый review-уровень не добавляется.
7. Pipeline остаётся неизменным — уточняется только порядок внутри Этапа 6.

---

## Обоснование

### Преимущества

- минимальные изменения архитектуры;
- отсутствие дополнительного bottleneck;
- сохранение текущей мультиагентной структуры;
- повышение качества UI;
- улучшение дисциплины реализации;
- соответствие ADR-002 (roles/workflows разделены);
- соответствие ADR-003 (без расширения структуры MVP).

### Недостатки

- отсутствие стратегического UX governance;
- отсутствие отдельного UX-review;
- межмодульная консистентность зависит от дисциплины Frontend Dev.

---

## Последствия

- `.pen` файлы становятся обязательным source of truth для UI.
- Frontend Dev обязан включать UX/UI sub-mode при UI-задачах.
- Изменения UI без обновления `.pen` запрещены.
- Возможен переход к полноценному UX Tier в будущем.

---

## Возможная эволюция

На более зрелом этапе развития проекта возможно:

- выделение UX/UI Director в отдельный Tier-1 агент;
- добавление UX-review в review-pipeline;
- введение глобальной дизайн-стратегии и governance.
