## 2. Strategic Governance Context

G24 created a canonical docs-only semantic drift monitoring register. That was intentionally not a monitoring system, compliance system, runtime control, approval engine, or governance authority layer.

G25 exists because anti-drift governance can itself drift. A register that protects against semantic drift can be misread as a gate, a mandatory authority hierarchy, or a hidden certification process.

Strategic question:

```text

```

G25 answers that question at the docs-only semantic level.
