## Governance note: два файла Geo Canon v1

**`docs/architecture/Geo_Canon_v1.md`** — расширенный ранний canon и материал для обсуждения SSOT: полный контекст, сервисные и миграционные заметки. Его используют, когда нужна глубина и история формулировок, а не только рабочая фиксация текущего этапа.

**`docs/architecture/geo/geo_canon_v1.md`** — сжатый **active milestone reference** для текущего этапа: опорная формулировка для планирования и review в рамках текущего milestone.

При расхождениях между файлами решение фиксируется явно (обновление документов и, при необходимости, ADR), а не выбором "какой путь короче". Эта заметка не добавляет новых архитектурных требований, а фиксирует порядок использования двух существующих артефактов.
