## Atlas Card Canon v1

**Статус**: standard v1  
**Область**: все карточки Atlas (Place Card, Showplace Card, Business Card)  
**Цель**: формализованный, машиночитаемый канон карточек Atlas для единообразного визуального представления контента.

См. также:
- `docs/modules/atlas/category_axis_v1.md`
- `docs/standards/search_conventions_v1.md`

---

## Принцип

**Карточка Atlas — это витрина знаний, а не статья.**

Контент **интерпретируется и структурируется**, а не выводится "как есть" (сырой markdown). Канон обязателен для:
- Place Card (Showplace)
- Place Card (Business)
- (в будущем) Business Card (расширенная версия)

---

## Базовая структура карточки (обязательная последовательность)

### 1. Hero
**Обязательный блок.**

- **Title**: название места (крупный шрифт, белый текст)
- **Subtitle / Type**: категория или тип (например, "UNESCO World Heritage", "Заведение")
- **Location**: город, страна (опционально)
- **Badges**: визуальные бейджи для статусов (UNESCO, Verified, Category)
- **Gradient background**: 
  - Showplace: `from-rose-600 to-amber-500`
  - Business: `from-amber-700 to-orange-500`

### 2. Media
**Обязательный блок.**

- **Gallery / Slider**: горизонтальная галерея изображений (до 5 фото)
- **Fallback**: градиентный placeholder, если фото отсутствуют
- **Carousel controls**: стрелки навигации, индикатор позиции

### 3. Quick Facts
**Опциональный, но рекомендуется.**

Компактный блок с ключевой информацией:
- **Location**: адрес, координаты (с иконкой MapPin)
- **Schedule**: часы работы (с иконкой Clock)
- **Price**: уровень цен или входной билет (с иконкой 💰)
- **Rating**: рейтинг TripAdvisor/Google (с иконкой Star), если доступен

**Визуальное представление**: горизонтальная сетка или компактный список с иконками.

### 4. Tags Row
**Опциональный.**

- Горизонтальный ряд тегов (Chips)
- Цвет: `bg-slate-100 text-slate-700`

### 5. Content Sections (динамические блоки)

Секции контента, интерпретированные из markdown. Порядок определяется приоритетом секции.

#### Showplace секции (приоритет отображения):

1. **Why it matters** (`whyImportant`)
   - **Тон**: `red` (rose-50/rose-200)
   - **Формат**: список с иконками (3–5 буллетов)
   - **Иконки**: извлекаются из markdown (эмодзи) или маппятся на lucide-react иконки

2. **Structure** (`structure`)
   - **Тон**: `amber` (amber-50/amber-200)
   - **Формат**: структурированный список с подзаголовками и иконками
   - **Пример**: "Ворота Ngo Mon", "Тронный зал Thai Hoa" с иконками

3. **Tickets** (`tickets`)
   - **Тон**: `sky` (sky-50/sky-200)
   - **Формат**: акцентные блоки для цен + список деталей
   - **Визуально**: выделенные блоки для разных типов билетов (взрослый/детский/комплексный)

4. **Time Allocation** (`timeAllocation`)
   - **Тон**: `emerald` (emerald-50/emerald-200)
   - **Формат**: акцентные блоки с вариантами времени
   - **Пример**: "Быстрый осмотр: 1.5–2 часа", "Полное погружение: 5–6 часов"
   - **Визуально**: цветные карточки с иконками

5. **Photo Spots** (`photoSpots`)
   - **Тон**: `amber` (amber-50/amber-200)
   - **Формат**: список мест с иконкой камеры

6. **Practical Tips** (`practicalTips`)
   - **Тон**: `sky` (sky-50/sky-200)
   - **Формат**: список советов с иконками (лучшее время, одежда, вода и т.д.)

7. **History** (`history`)
   - **Тон**: `red` (rose-50/rose-200)
   - **Формат**: параграфы с акцентами на ключевые даты

8. **Nearby** (`nearby`)
   - **Тон**: `emerald` (emerald-50/emerald-200)
   - **Формат**: сетка карточек связанных мест (название, описание, расстояние)

9. **Interesting Fact** (`interestingFact`)
   - **Тон**: `amber` (amber-50/amber-200)
   - **Формат**: акцентный блок с иконкой

#### Business секции (приоритет отображения):

1. **Why Visit** (`whyVisit`)
   - **Тон**: `amber` (amber-50/amber-200)
   - **Формат**: список с иконками (3–5 буллетов)

2. **Must Try** (`mustTry`)
   - **Тон**: `sky` (sky-50/sky-200)
   - **Формат**: список блюд/напитков с описаниями

3. **Prices** (`prices`)
   - **Тон**: `emerald` (emerald-50/emerald-200)
   - **Формат**: акцентные блоки для цен или ценовой диапазон

4. **How to Get** (`howToGet`)
   - **Тон**: `amber` (amber-50/amber-200)
   - **Формат**: список способов добраться с иконками транспорта

5. **Service** (`service`)
   - **Тон**: `sky` (sky-50/sky-200)
   - **Формат**: список (языки, Wi-Fi, розетки, тишина)

6. **Nuances** (`nuances`)
   - **Тон**: `amber` (amber-50/amber-200)
   - **Формат**: список советов

7. **Local Value** (`localValue`)
   - **Тон**: `emerald` (emerald-50/emerald-200)
   - **Формат**: параграф о культурной ценности

8. **Photo Tips** (`photoTips`)
   - **Тон**: `sky` (sky-50/sky-200)
   - **Формат**: список мест для фото

### 6. Footer
**Опциональный.**

- **Status**: "UNESCO World Heritage - Verified" или "Editorial Verified"
- **Category**: категория места (например, "Historic Site - Imperial Architecture")
- **Визуально**: sticky bar или компактный блок внизу

## Типы блоков (машиночитаемо)

### Обязательные блоки

- `hero` — всегда присутствует
- `media` — всегда присутствует (может быть placeholder)

### Опциональные блоки (приоритет отображения)

1. `quickFacts` — высокий приоритет (если есть данные)
2. `tags` — средний приоритет
3. Контентные секции — по порядку, определённому в sectionDefs
4. `footer` — низкий приоритет

### Fallback-логика

- Если секция отсутствует в markdown → блок не отображается (не показываем пустые блоки)
- Если есть только `overviewMarkdown` без секций → показываем один блок "Описание" с тоном `sky`
- Если контент полностью отсутствует → показываем `EMPTY_TEXT`: "Данные уточняются редакцией."

### Обработка длинного текста

- **Параграфы**: рендерятся как обычный текст с отступами
- **Списки**: интерпретируются как буллеты с иконками (если есть эмодзи в markdown)
- **Подзаголовки внутри секций**: рендерятся как подзаголовки с меньшим размером шрифта

### Извлечение списков / советов / фактов

- **Списки с эмодзи**: эмодзи извлекаются и маппятся на lucide-react иконки (или остаются как эмодзи)
- **Акцентные блоки**: специальные паттерны (например, "💰 Входной билет: ~150 000 VND") → выделяются как акцентный блок
- **Время**: паттерны типа "1.5–2 часа" → акцентный блок с иконкой Clock

## Визуальные паттерны

### Иконки

- **Источник**: lucide-react (предпочтительно) или эмодзи из markdown
- **Размер**: 14–16px для списков, 20–24px для акцентных блоков
- **Цвет**: `text-slate-400` для обычных, цвет тона для акцентов

### Акцентные блоки

Используются для:
- **Цены**: выделенные блоки с границами и фоном
- **Время**: цветные карточки с иконками (синий/зелёный/оранжевый)
- **Важная информация**: блоки с более тёмным фоном

### Цветовая схема тонов

- `red`: `bg-rose-50 border-rose-200`
- `amber`: `bg-amber-50 border-amber-200`
- `emerald`: `bg-emerald-50 border-emerald-200`
- `sky`: `bg-sky-50 border-sky-200`
- `purple`: `bg-purple-50 border-purple-200`

### Типографика

- **Заголовки секций**: `font-semibold text-slate-900 mb-2`
- **Текст контента**: `text-sm text-slate-700`
- **Акценты**: `font-medium` для важных фрагментов

---

## Правила интерпретации markdown

1. **Заголовки `##` или `###`**: парсятся как секции, нормализуются и маппятся на section keys
2. **Списки `-`**: интерпретируются как буллеты с иконками (если есть эмодзи)
3. **Эмодзи в начале строки**: извлекаются и используются как иконки
4. **Паттерны цен**: `💰 ~150 000 VND` → акцентный блок
5. **Паттерны времени**: `⏱️ 2–3 часа` → акцентный блок с иконкой Clock
6. **Координаты**: извлекаются из метаданных или текста

```
📸 Впечатляющее сочетание дворцов...
```
