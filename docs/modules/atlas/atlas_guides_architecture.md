1. Назначение документа
Настоящий документ определяет архитектуру раздела «Гайды» модуля Atlas Asia.
Гайды являются структурированными, обновляемыми, объективными справочниками и не являются блог-публикациями.
Документ служит единым источником архитектурной истины для:
•	структуры данных
•	логики вкладок
•	хранения контента
•	работы Cursor
•	миграции в Neon
•	будущей CMS
•	интеграции с другими модулями
•	масштабирования проекта
________________________________________
2. Концептуальная модель
2.1 Что такое гайд?
Гайд — это:
•	структурированный документ принятия решений
•	хаб, объединяющий несколько модулей
•	контейнер с модульными секциями
•	редакционный (объективный) материал
•	SEO-ориентированный справочник
Гайд ≠ блог
Гайд ≠ статья
Гайд = Knowledge Hub
________________________________________
3. Типы гайдов (guide_type)
Каждый гайд имеет поле guide_type.
Поддерживаемые типы:
•	strategic — стратегический
•	comparative — сравнительный
•	route — маршрутный
•	niche — нишевой
•	event — событийный
•	housing — жильё
•	visa — визовый
•	work_infra — работа и инфраструктура
•	climate — климатический
Тип гайда определяет набор вкладок по умолчанию.
________________________________________
4. Универсальная система вкладок (Universal Guide UI Framework)
Гайд использует 11 универсальных вкладок-контейнеров:
overview      — Обзор
compare       — Контекст и сравнение
locations     — Локации
route         — Маршрут / План
map           — Карта
practice      — Практика
events        — События
places        — Места
audience      — Для кого
faq           — FAQ
experience    — Опыт
Вкладки — это контейнеры.
Каждый гайд активирует только релевантные вкладки.
Пустые вкладки автоматически скрываются.
________________________________________

Правило:

•	Маршрутные гайды обязаны иметь route и map.
•	Сравнительные гайды обязаны иметь compare.

________________________________________
8. Правила отображения вкладок
Вкладка отображается, если:
1.	is_enabled = true
2.	И существует:
o	хотя бы один непустой блок
o	или активный feed
Пустые вкладки не рендерятся.
________________________________________
9. Стандарт хранения Markdown (до внедрения CMS)
Все гайды хранятся как .md файлы:
content/atlas/guides/
Имя файла:
{type_prefix}.{slug}.md
Пример:
str.digital-nomads-sea-2026.md

11. Медиа-политика (Media Policy v1)
Медиа хранится в R2.
Структура:
guides/{slug}/hero.jpg
guides/{slug}/...
Правила:
•	В Markdown не вставляются прямые URL
•	Хранится только ключ R2
•	CDN-трансформации реализуются позже
•	Допустимо версионирование файлов (hero.v2.jpg)

12. Интеграционная модель
Гайды являются центральным хабом и интегрируются с:
•	Atlas (города, места)
•	Pulse (события)
•	Blog (опыт)
•	Rielt (жильё)
•	Quest (маршруты)
•	Guru (AI-рекомендации)
________________________________________
13. SEO и перелинковка
Каждый гайд должен:
•	ссылаться на связанные гайды
•	ссылаться на города и места
•	избегать дублирования Blog-контента
•	содержать структурированные таблицы
