VIP Value System v1 (SSOT)

Go2Asia — Product & Psychological Model of VIP Activation

---

1. Назначение
Документ фиксирует:
•	за что пользователь платит 1000 руб / месяц; 
•	какие механики делают VIP желанным и повторно покупаемым; 
•	как VIP конвертирует активность в ценность; 
•	как удерживать пользователя в цикле подписки. 

---

2. Главный принцип
VIP — это не подписка.
VIP — это активация накопленной ценности пользователя.

---

3. Базовая модель ценности
VIP состоит из четырёх слоёв:

3.1 Spend Layer (потребление)
Что открывает VIP:
•	покупка ваучеров за Points 
•	покупка премиум-ваучеров (Points + NFT) 
•	покупка квестов 
•	обмен Points → NFT 
👉 Без VIP Points почти не имеют практической ценности

3.2 Unlock Layer (разблокировка)
VIP разблокирует:
•	Points за рефералов 
•	Points за субрефералов 
•	скрытую накопленную ценность 
👉 Это самый сильный триггер покупки

3.3 Network Layer (доход сети)
VIP включает:
•	10% от Points рефералов 
•	2% от Points субрефералов 
👉 Пользователь начинает зарабатывать не только сам, но и через сеть

3.4 Status Layer (статус и доступ)
VIP даёт:
•	доступ к премиум-ваучерам 
•	доступ к квестам 
•	доступ к NFT-экономике 
•	социальный статус 

---

4. Формула ценности VIP
👉
VIP Value = Spend + Unlock + Network + Status

---

5. Основной триггер покупки
VIP покупается не из-за одной причины, а из-за давления:

5.1 Points Pressure
•	Points накапливаются быстро 
•	Points не тратятся без VIP 
👉 создаётся напряжение

5.2 Locked Value Pressure
•	у пользователя есть Points 
•	но часть из них заблокирована 
👉 создаётся ощущение потери

5.3 Network Pressure
•	сеть уже генерирует Points 
•	но пользователь не получает их 
👉 страх упущенной выгоды

5.4 Consumption Desire
•	есть ваучеры 
•	есть квесты 
•	есть реальные выгоды 
👉 желание потратить

---

6. UX-реализация (критично)
VIP продаётся через интерфейс.

6.1 Wallet Screen
Показывать:
•	Available Points 
•	Locked Points 
•	Network Points 
Пример:
•	У вас: 42 000 Points 
•	Заблокировано: 25 000 
•	Доход сети (7 дней): +6 300 
👉 кнопка: “Активировать VIP”

6.2 Voucher Screen
Показывать:
•	реальные выгоды в рублях 
•	сколько Points нужно 
•	что заблокировано без VIP 

6.3 Trigger Screen
Перед покупкой:
👉
“Вы теряете 320 Points в день без VIP”

6.4 Instant Reward
После покупки VIP:
•	сразу дать: 
o	доступ к ваучеру 
o	контакт с бизнесом 
o	ощущение выгоды 

---

7. Addictive Loop
Активность → Points → Locked Points → Network Growth
→ Давление → Покупка VIP → Трата Points → Получение выгоды
→ Рост активности → ещё больше Points

---

8. Retention модель
VIP удерживается если:
👉
Points Earned ≈ Points Spent

Если:
•	зарабатывает больше чем тратит
→ frustration 
•	тратит больше чем зарабатывает
→ disengagement 

Баланс:
👉 50–80% spend rate = идеал

---

9. Points Sink (куда уходят Points)
Чтобы экономика не ломалась:
•	ваучеры 
•	премиум-ваучеры (с NFT) 
•	квесты 
•	NFT mint 

---

10. Роль премиум-ваучеров
Премиум-ваучеры:
•	дают сильную выгоду 
•	требуют Points + NFT 
•	сжигают Points 
•	сжигают NFT 
👉 главный инструмент “сброса давления”

---

11. Поведение пользователя

Spacer:
•	копит Points 
•	не может тратить 

VIP:
•	тратит Points 
•	зарабатывает с сети 
•	участвует в экономике 

PRO:
•	зарабатывает G2A 
•	управляет бизнесом 
•	создаёт квесты 

---

12. Главная задача продукта
👉
Сделать так, чтобы пользователь каждый месяц хотел:
•	разблокировать Points 
•	не потерять сетевой доход 
•	получить выгоду 

---

13. Главные метрики

13.1 VIP Conversion Rate
% пользователей, купивших VIP

13.2 Points Accumulation Rate
сколько Points пользователь зарабатывает

13.3 Points Spend Rate
Points spent / Points earned

13.4 VIP Retention
сколько месяцев пользователь остаётся VIP

13.5 Network Growth
рост рефералов

---

14. Ключевые риски

14.1 Points обесцениваются
если нет хороших ваучеров

14.2 Нет давления
если Points мало

14.3 Нет сети
если слабая рефералка

14.4 Нет “вау-ценности”
если ваучеры слабые

---

15. Главный инсайт
👉
VIP продаётся не ценой, а давлением и упущенной выгодой

---

16. Финальная формула
👉
Points → Pressure → VIP → Spend + Network → Growth
