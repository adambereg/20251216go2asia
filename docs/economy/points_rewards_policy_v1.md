## 4. Canonical Economy Doctrine

The Points / Rewards doctrine can be read through these principles:

```text
Points are internal utility, not money.
VIP is activation layer, not payout layer.
Origin is metadata, not currency type.
Visible != spendable.
Projected != ledger truth.
Conditional != available.
Available != payout.
Referral / network != MLM.
RF / voucher != cashback or settlement.
Progression != paid task.
Readiness != implementation.
Soft policy != enforcement.
```

Human-readable interpretation:

- Points represent internal participation and utility within Go2Asia.
- VIP makes accumulated internal utility useful where runtime-aligned policy and actual implementation allow it.
- Referral and network language must remain participation-oriented.
- RF / voucher language must remain practical-utility and consumption-oriented.
- Progression, quests, badges, and achievements must remain identity, prestige, and retention language.
- Future ledger language prepares vocabulary for later value history; it is not ledger activation.
- Abuse, dispute, correction, reversal, and recovery language protects trust; it is not punishment or enforcement.

## 7. Core Economy Flows

These flows are high-level semantic flows only.

They are not runtime flows.

They are not implementation flows.

### Activity to Utility

```text
Activity -> Points -> VIP -> Spend -> Utility -> Retention
```

Interpretation:

Participation may create internal utility. VIP is the activation layer that can make internal utility useful where policy and runtime separately allow. Spend creates practical or experiential utility. Utility supports retention.

### Referral to VIP Pressure

```text
Referral -> Conditional Utility -> VIP Pressure
```

Interpretation:

Referral participation may create conditional or projected value. That value should be described as participation utility and activation pressure, not income, commission, payout, or passive earnings.

### RF / Voucher Consumption

```text
RF / Voucher -> Practical Utility -> Sink Pressure
```

Interpretation:

Vouchers connect Points to practical consumption and ecosystem usefulness. They are not payment settlement, cashback, merchant remittance, or partner payout.

### Quest / Badge Progression

```text
Quest / Badge -> Progression -> Retention
```

Interpretation:

Quests, badges, and achievements create recognition, memory, identity, and return motivation. They are not paid tasks, gig work, or marketplace activation.

### Prestige and Long-Term Engagement

```text
Progression -> Identity / Prestige -> Long-term Engagement
```

Interpretation:

Prestige and identity signals create attachment to the ecosystem. Future NFT compatibility language remains a future boundary, not minting, export, marketplace, or on-chain activation.
