Этот план на 10 дней построен по принципу: Манила → Палаван → Боракай.

Он сбалансирован, реалистичен и не требует сверхсложных перелётов.

## Общая логика маршрута

```block
type: list
variant: ordered
items:
  - День 1–2 — Манила (адаптация + история)
  - День 3–6 — Палаван (природа и острова)
  - День 7–10 — Боракай (пляж и расслабление)
```

Перемещения — внутренними перелётами (1–1,5 часа).

## ДЕНЬ 1–2: Манила

### Зачем вообще начинать с Манилы?

Многие советуют «прилететь и сразу улететь на острова». Но 1–2 дня в столице помогают:

```block
type: list
variant: bulleted
items:
  - привыкнуть к климату
  - адаптироваться к часовому поясу
  - увидеть культурную сторону страны
```

### Где остановиться

Лучшие районы для короткого визита:

```block
type: list
variant: bulleted
items:
  - Makati — современный деловой центр
  - Bonifacio Global City (BGC) — чисто, безопасно, удобно
```

Избегайте случайных районов без опыта — город большой и контрастный.

### Что посмотреть

```block
type: list
variant: bulleted
items:
  - Intramuros — старый испанский квартал с крепостными стенами
  - Rizal Park — зелёная зона в центре
  - Национальный музей — если хочется глубже понять историю
```

### Реалистичный бюджет на 2 дня в Маниле

```block
type: table
headers: ["Статья", "Сумма"]
rows:
  - ["Отель 3–4*", "60–120 $ / ночь"]
  - ["Еда", "20–40 $ / день"]
  - ["Grab", "5–15 $"]
  - ["Экскурсии", "10–20 $"]
```

**Итого: ~200–300 $ на 2 дня.**

## ДЕНЬ 3–6: Палаван (Эль-Нидо или Корон)

Палаван — это то, за чем обычно летят на Филиппины.

Белые пляжи, бирюзовая вода, карстовые скалы.

### Как добраться

Из Манилы:

```block
type: list
variant: bulleted
items:
  - перелёт до Puerto Princesa, El Nido или Coron
  - 1–1,5 часа
```

Лучше лететь напрямую в Эль-Нидо или Корон, чтобы сократить трансферы.

### Что выбрать — Эль-Нидо или Корон?

**Эль-Нидо:**

```block
type: list
variant: bulleted
items:
  - больше пляжей
  - разнообразные island hopping туры
  - немного больше туристов
```

**Корон:**

```block
type: list
variant: bulleted
items:
  - лагуны
  - дайвинг
  - меньше пляжей, больше скал
```

Для первого раза проще выбрать Эль-Нидо.

### Программа на 4 дня

**День 3** — Заселение и пляж

Отдых после перелёта, вечерний закат.

**День 4** — Island Hopping Tour A

```block
type: list
variant: bulleted
items:
  - Big Lagoon
  - Small Lagoon
  - Secret Beach
```

**День 5** — Tour C

```block
type: list
variant: bulleted
items:
  - Hidden Beach
  - Helicopter Island
```

**День 6** — Свободный день

Скутер, соседние пляжи или просто отдых.

### Бюджет Палавана (4 дня)

```block
type: table
headers: ["Статья", "Сумма"]
rows:
  - ["Гестхаус", "30–70 $ / ночь"]
  - ["Отель 3–4*", "80–200 $"]
  - ["Island hopping", "25–40 $ / тур"]
  - ["Еда", "20–40 $ / день"]
```

**Средний бюджет: 400–800 $ за 4 дня** (в зависимости от уровня жилья).

## ДЕНЬ 7–10: Боракай

После активного Палавана Боракай — это «плавный финал».

### Почему Боракай

```block
type: list
variant: bulleted
items:
  - один из самых красивых пляжей ЮВА
  - развитая инфраструктура
  - идеален для отдыха без логистики
```

### Что делать

**День 7** — Заселение, White Beach

Пляжная линия 4 км, мягкий белый песок.

**День 8** — Водные активности

```block
type: list
variant: bulleted
items:
  - SUP
  - парасейлинг
  - снорклинг
```

**День 9** — Закат и рестораны

Боракай — один из лучших закатов региона.

**День 10** — Спокойный финал

Утро у воды и вылет в Манилу.

### Бюджет Боракая (4 дня)

```block
type: table
headers: ["Статья", "Сумма"]
rows:
  - ["Отель 3*", "70–120 $ / ночь"]
  - ["Хороший отель", "150–300 $"]
  - ["Еда", "25–50 $ / день"]
  - ["Активности", "20–50 $"]
```

**Итого: 500–1000 $ на 4 дня.**

## Перелёты и логистика

Средняя цена внутреннего перелёта:

```block
type: list
variant: bulleted
items:
  - 40–100 $
```

Планируйте перелёты заранее, особенно в сезон.

## Общий бюджет на 10 дней

### 💰 Экономный режим

**~1200–1500 $** (жильё попроще, без люкса)

### 💼 Комфортный режим

**~1800–2500 $**

### 🌴 Курортный режим

**3000 $+**

## Частые ошибки

```block
type: list
variant: bulleted
items:
  - Пытаться посетить 4–5 островов за 10 дней
  - Игнорировать погодный сезон

  - Ожидать «нетуристическую» атмосферу в Боракае
```

## Итог

Филиппины для первого раза — это не марафон по островам.

Это комбинация:

```block
type: list
variant: bulleted
items:
  - городской адаптации
  - природной красоты
  - расслабленного пляжного финала
```

Манила даёт контекст.

Палаван — «вау-эффект».

Боракай — ощущение отпуска.

Если маршрут зайдёт, в следующий раз можно добавить:

```block
type: list
variant: bulleted
items:
  - Себу
  - Сиаргао
  - Бохоль
```

Но для первых 10 дней этот план — оптимальный баланс впечатлений и логистики.

