Я много лет снимаю в Таиланде, Вьетнаме, Индонезии именно на телефон. Ниже — не "вдохновляющие советы", а конкретные рабочие принципы, которые реально улучшают картинку.

## 1. Свет — важнее модели iPhone

Можно снимать на iPhone 12 и получить лучшее видео, чем на 15 Pro, если правильно выбрать свет.

Главный принцип:

Снимайте утром или перед закатом.

Лучшее время:

```block
type: list
variant: bulleted
items:
  - 6:00–8:00 — мягкий свет, меньше людей
  - 16:30–18:30 — золотой час
```

Худшее время:

```block
type: list
variant: bulleted
items:
  - 11:00–15:00 — жёсткое тропическое солнце
  - съёмка "в лоб" под прямым солнцем
```

```block
type: sidebar
variant: tip
title: "Чек-лист по свету"
text: "Не снимайте людей под прямым полуденным солнцем. Используйте тень зданий. Поворачивайтесь к солнцу боком, а не спиной. Закаты снимайте с экспозицией ниже (уменьшайте яркость на экране)."
```

## 2. Настройки камеры — минимум автоматики

Откройте настройки камеры и сделайте 3 вещи:

### 1. Включите сетку

Настройки → Камера → Сетка

Это поможет держать горизонт.

### 2. Снимайте в 4K (если планируете монтаж)

Настройки → Камера → Запись видео → 4K 30 fps

### 3. Заблокируйте фокус и экспозицию

Зажмите экран → AE/AF Lock

И отрегулируйте яркость вручную.

```block
type: sidebar
variant: warning
title: "Ошибка №1"
text: "Снимать всё в авто-режиме без контроля экспозиции."
```

## 3. Композиция — 3 простых правила

В travel-контенте важна структура кадра.

### Правило 1 — правило третей

Не ставьте объект в центр всегда.

Смещайте его по линиям сетки.

### Правило 2 — глубина

Используйте:

```block
type: list
variant: bulleted
items:
  - передний план (листья, стол, чашка кофе)
  - средний план (человек)
  - задний план (город, море)
```

ЮВА — визуально насыщенная среда. Используйте это.

### Правило 3 — меньше хаоса

На рынках и в городах много деталей.

Уберите лишнее из кадра:

```block
type: list
variant: bulleted
items:
  - шагните в сторону
  - приблизьтесь
  - смените угол
```

## 4. Как снимать в условиях жары и влажности

ЮВА — сложная среда для техники.

Проблемы:

```block
type: list
variant: bulleted
items:
  - перегрев
  - запотевание камеры
  - влажность
```

```block
type: sidebar
variant: tip
title: "Чек-лист"
text: "Не оставляйте телефон под солнцем. После кондиционера дайте камере 'прогреться' перед съёмкой. Используйте простой чехол, а не толстый кейс."
```

## 5. Съёмка людей в Азии

Очень важно уважение.

Правило:

Не направляйте камеру в лицо без разрешения.

Особенно:

```block
type: list
variant: bulleted
items:
  - на рынках
  - в храмах
  - у пожилых людей
```

Лучший способ:

```block
type: list
variant: bulleted
items:
  - улыбка
  - лёгкий кивок
  - жест "можно?"
```

## 6. Съёмка уличной еды — практический подход

ЮВА = street food.

Но большинство снимает еду неправильно.

Не делайте:

```block
type: list
variant: bulleted
items:
  - кадр сверху с хаотичным столом
  - съёмка при жёлтом искусственном свете
```

Делайте:

```block
type: list
variant: checklist
items:
  - Снимайте под углом 45°
  - Добавляйте движение (ложка, пар, нарезка)
  - Снимайте процесс приготовления
```

Процесс всегда интереснее, чем статичная тарелка.

## 7. Вертикально или горизонтально?

Если снимаете для:

```block
type: list
variant: bulleted
items:
  - Reels / Shorts → вертикально
  - YouTube / блог → горизонтально
```

Ошибка — пытаться потом кадрировать горизонтальное видео под вертикаль.

## 8. Стабилизация без стабилизатора

Вам не нужен дорогой gimbal.

Базовые приёмы:

```block
type: list
variant: bulleted
items:
  - держите телефон двумя руками
  - прижимайте локти к корпусу
  - двигайтесь медленно
  - используйте "шаг пятка–носок"
```

Простой лайфхак:

Опирайтесь на стену, столб или перила.

## 9. Цвет и монтаж

ЮВА яркая, но легко уйти в "перенасыщенный ад".

Не делайте:

```block
type: list
variant: bulleted
items:
  - +100 насыщенности
  - чрезмерный HDR
  - агрессивные фильтры
```

Минимальная обработка:

```block
type: list
variant: checklist
items:
  - Чуть уменьшить яркость
  - Добавить немного контраста
  - Слегка повысить резкость
  - Убрать избыточный жёлтый оттенок
```

## 10. Типовые ошибки travel-контента

```block
type: list
variant: bulleted
items:
  - Слишком длинные видео
  - Резкие движения камеры
  - Съёмка всего подряд
  - Игнорирование звука
```

## 11. Звук — недооценённый инструмент

Звук рынка, моря, дождя в Ханое — создаёт атмосферу сильнее, чем фильтр.

Иногда лучше снять 20 секунд чистого звука, чем говорить в кадре.

## 12. Мини-чек-лист перед съёмкой

```block
type: list
variant: checklist
items:
  - Протёрта ли камера?
  - Горизонт ровный?
  - Свет мягкий?
  - Нет ли пересвета?
  - Понимаю ли я, зачем снимаю этот кадр?
```

Если вы не знаете, зачем снимаете — не снимайте.

## 13. Что реально работает в ЮВА

```block
type: list
variant: bulleted
items:
  - контраст старого и нового (неон + храм)
  - люди в движении
  - еда в процессе
  - отражения после дождя
  - утренние улицы без толпы
```

## Итог

iPhone — достаточный инструмент для travel-контента в ЮВА.

Но результат зависит не от модели, а от:

```block
type: list
variant: bulleted
items:
  - понимания света
  - контроля композиции
  - уважения к среде
  - умеренной обработки
```

Юго-Восточная Азия даёт идеальный материал.

Ваша задача — не испортить его лишними фильтрами и спешкой.

type: blockquote
text: "Качество контента определяется не камерой, а взглядом человека, который её держит."
