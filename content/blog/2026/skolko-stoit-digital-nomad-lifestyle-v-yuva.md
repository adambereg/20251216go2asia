## 1. Из чего вообще состоит бюджет digital nomad?

Прежде чем сравнивать города, важно понять структуру расходов.

Основные статьи:

## 🇹🇭 Бангкок

Бангкок — самый "мегаполисный" вариант в регионе. Метро, международные школы, развитая медицина, сотни коворкингов.

### Жильё

| Тип | Цена / месяц |
|-----|--------------|
| Студия (30–40 м²) | 500–800 $ |
| 1-bedroom | 700–1200 $ |
| 2-bedroom | 1200–2000 $ |

Районы Sukhumvit, Ari, Silom — дороже, но удобнее.

### Еда

```block
type: list
variant: bulleted
items:
  - Уличная еда: 2–4 $
  - Кафе: 8–15 $
  - Рестораны: 15–30 $
```

Средний бюджет: 300–500 $ / месяц.

### Коворкинг

100–200 $ / месяц.

### Итого по Бангкоку

```block
type: list
variant: bulleted
items:
  - 💰 Эконом: 1200–1400 $
  - 💼 Комфорт: 1600–2000 $
  - 🌇 Городской премиум: 2500 $+
```

## 🇻🇳 Дананг

Дананг — сбалансированный вариант: море + город.

### Жильё

| Тип | Цена / месяц |
|-----|--------------|
| Студия | 300–450 $ |
| 1-bedroom | 450–650 $ |
| 2-bedroom | 650–1000 $ |

### Еда

```block
type: list
variant: bulleted
items:
  - Уличная еда: 1,5–3 $
  - Кафе: 6–12 $
```

Бюджет: 250–400 $ / месяц.

### Коворкинг

80–150 $ / месяц.

### Итого по Данангу

```block
type: list

  - 💼 Комфорт: 1300–1600 $
  - 🌊 Вид на море: 1800–2200 $
```

## 🇮 Бали

Бали — самый "комьюнити-ориентированный" вариант.

### Жильё (Чангу)

| Тип | Цена / месяц |
|-----|--------------|
| Комната | 500–800 $ |
| Вилла 1-bedroom | 1200–2000 $ |

### Еда

```block
type: list
variant: bulleted
items:
  - Локальная: 3–5 $
  - Кафе: 8–20 $
```

Бюджет: 350–600 $ / месяц.

### Коворкинг

120–250 $ / месяц.

### Итого по Бали

```block
type: list
variant: bulleted
items:
  - 💰 Скромно: 1500 $
  - 💼 Комфорт: 1800–2500 $
  - 🌴 Вилла + активность: 2500–3500 $
```

Бали — уже не бюджетный вариант.

## 🇲🇾 Куала-Лумпур

KL — самый структурированный и "европейский" вариант.

### Жильё

| Тип | Цена / месяц |
|-----|--------------|
| Студия | 600–900 $ |
| 1-bedroom | 800–1200 $ |
| 2-bedroom | 1200–1800 $ |

Часто включены бассейн, спортзал, охрана.

### Еда


### Коворкинг

120–200 $.

## 2. Дополнительные расходы

### Визы

```block
type: list
variant: bulleted
items:
  - Таиланд — регулярные продления
  - Вьетнам — e-visa + выезды
  - Индонезия — визовые агентства
  - Малайзия — проще при краткосрочном пребывании
```

Закладывайте 50–150 $ / месяц в среднем.

### Страховка

60–150 $ / месяц.

### Путешествия внутри региона

Бюджетные перелёты — 40–120 $.

## 4. Главный вывод

Digital nomad lifestyle в ЮВА в 2026 году стоит:

```block
type: list
variant: bulleted
items:
  - Минимум 1000–1200 $ (очень скромно)
  - Комфортно 1500–2000 $
  - Сильно комфортно 2500 $+
```

Регион остаётся дешевле Европы, но уже не "рай за копейки".

## 5. Как выбрать город под себя

```block
type: list
variant: bulleted
items:
  - Хотите мегаполис → Бангкок
  - Море + бюджет → Дананг
  - Комьюнити + атмосфера → Бали
  - Структура и порядок → Куала-Лумпур
```

Лучший способ понять — пожить по месяцу в двух местах.
