# Инструкции по извлечению данных из результатов SQL-скриптов

## Проблема

SQL-скрипты выводят несколько секций результатов, и Excel экспортирует их в отдельные колонки.  
Для полного заполнения `docs/audits/neon_schema_audit.md` нужны данные из всех секций.

## Решение

### Вариант 1: Экспорт в CSV (рекомендуется)

1. В Neon Console SQL Editor после выполнения скрипта:
   - Нажмите на результат каждого SELECT запроса
   - Используйте кнопку "Export" → "CSV"
   - Сохраните файлы с понятными именами:
     - `01_tables_and_views.csv`
     - `02_columns.csv`
     - `03_primary_keys.csv`
     - `04_unique_constraints.csv`
     - `05_foreign_keys.csv`
     - `06_indexes.csv`
     - `07_enum_types.csv`
     - `08_table_sizes.csv`
     - `09_summary.csv`

2. Откройте CSV файлы в текстовом редакторе и скопируйте содержимое

### Вариант 2: Копирование из Excel

1. Откройте каждый Excel файл
2. Выделите все данные (Ctrl+A)
3. Скопируйте (Ctrl+C)
4. Вставьте в текстовый файл или прямо в чат

### Вариант 3: Описание содержимого

Опишите содержимое каждой колонки:
- Колонка 4: что это? (таблицы, колонки, constraints?)
- Колонка 9: что это?
- И т.д.

1. ✅ **Tables and Views** — уже есть из скриншота
2. ❌ **Columns by Table** — нужны для понимания структуры таблиц

## Быстрый способ

Если хотите быстро заполнить документ:

1. Запустите все скрипты последовательно
2. Для каждого скрипта скопируйте весь вывод (Ctrl+A в SQL Editor → Copy)
3. Вставьте результаты в отдельные текстовые файлы:
   - `audit_results/01_schema_inventory.txt`
   - `audit_results/02_data_health_core.txt`
   - `audit_results/03_data_health_atlas.txt`
   - и т.д.

4. Предоставьте эти файлы для анализа
